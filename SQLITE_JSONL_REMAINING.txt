五项缺口与最终实现

1. history 正常追加不再复制完整 map
   每个 catalog store 保留一个带 RWMutex 的 historyIndexData。
   解析时仅构建本次变更 map；SQLite 成功提交后，在短写锁内合并变化。
   读者只在单条 lookup 时持有读锁，并取得值副本。旧读者得到的是同步共享视图，
   可以看到本进程稍后成功提交的追加；它不是不可变的历史时间点快照。
   文件重建或检测到其他连接修改后，允许重新装载完整 map。
   同一 store 的更新串行；读者锁不跨源文件或 SQLite I/O。
   提交失败仅返回请求私有的少量变化，不能污染共享的已提交索引。
   有效但无换行的尾记录也只叠加在请求私有 map；不推进持久游标。
   删除 cloneHistorySessions，不增加持久变更日志或跨进程 map 同步。

2. text/messages 模式切换不再重读尚未提交的 JSONL 尾段
   messagesLoaded 只表示当前标准消息列表是否已装载，与本次请求展示模式分开。
   从文本切到消息列表时，读取并校验 SQLite 中已提交的消息，然后接上已有 pendingMessages。
   后续文本读取仍保留已有消息列表；追加同步更新它，避免失效后再次解析。
   保留已提交 offset/ordinal/generation 的并发校验；冲突时丢弃内存状态并恢复。
   完整消息列表返回给调用者时与缓存条目隔离，修改首条或 pending 尾条不会污染缓存。
   64 KiB/30 秒批次阈值不变，没有为了模式切换额外提交事务。

3. 真正共享一个 JSONL 窗口读取工具
   新增 readJSONLWindow，小范围复用行对齐、流式逐行读取、取消、EOF 和读取错误处理。
   history、preview、名称索引和完整元数据的窗口解析使用同一工具。
   128 KiB summary 的提前停止规则继续独立；它有自己的读取预算和停止条件。
   末尾完整 JSON 无换行仍可读取；是否临时展示、在哪里持久化由上层明确决定。
   请求窗口尚未读够就遇到 EOF，返回 UnexpectedEOF，防止截断时发布虚假进度。
   history 是可选的发现增强信息：源读取失败不阻断发现，不推进数据库；取消仍向上传递。
   工具采用 64 KiB 读缓冲；超大单行仍可能分配更多内存，不声称固定内存上限。

4. 删除全局 4096 项元数据 map
   删除 sessionFileCache、get/set/reset 及其调用者，不留下空实现或第二套失效逻辑。
   loader 只持有当前发现路径的 catalog 批量快照，context 释放后快照随之释放。
   单文件独立调用直接使用现有 catalog；新 loader 能读取其他连接更新的记录。
   数据库连接、history 和名称缓存各自的既有生命周期保持原有职责。

5. summary 记录真实扫描覆盖范围
   readSessionSummary 返回 consumed 字节数，session_meta.parsed_offset 存储实际扫描位置。
   增加 is_summary 字段，替换负 offset 哨兵；未读到 EOF 时消息数仍为 -1，表示未知。
   摘要不能作为完整元数据解析的续读基础，也不能降级同一来源的完整元数据。
   重开后仍保留覆盖范围与摘要标志。
   原业务库 conversion/migration 不变。派生缓存仍采用本补丁尚未发布的版本 4；
   不匹配的派生 schema 会隔离并从 JSONL 重建，不维护双格式读写。
   回归已模拟较早派生结构缺少 is_summary，确认能重建且源 JSONL 内容不变。

新增回归

remaining_plan_test.go 包含 9 项顶层回归，并有 JSONL 边界表驱动子项：
- 受控持有读锁，确认 SQLite 已提交时 map 尚未被并发修改，释放后才合并；不复制未变记录。
- 注入 SQLite INSERT 失败，共享 history 索引不变，请求仍能看到源数据，重试可恢复。
- 连续 12 次追加并反复 text/messages 切换，仅解析 12 个新窗口；未到阈值不写 checkpoint。
  修改返回列表首尾元素不污染缓存；强制提交后重开，14 条消息无丢失、无重复。
- JSONL 空窗口、无换行、未对齐起点、有界前缀、短读、非法窗口、取消和回调错误。
- summary 覆盖位置持久化；随后完整解析从零开始并得到准确消息数。
- loader 快照随 context 隔离，新请求不被全局旧元数据遮蔽。
- 解析中截断 history，发现正常退化，SQLite 游标不变。
- 解析中截断完整元数据，返回读取错误，不发布缓存记录。
- 较早派生缓存缺字段，隔离后重建，原始 JSONL 保持不变。

现有测试仅改用同步索引查询、去除已删除缓存的 reset、适配 summary 返回覆盖范围。
没有放宽消息可见性、事务原子性、零写入、页写预算或并发断言。
