## Why this prerelease exists

`helper stats` previously reported only the conversation-wide token total. That
made a long-lived Teams chat misleading after a model or service-tier switch:
the total could not show which model/tier actually consumed the tokens, and a
user could not compare the usage of the different portions of the conversation.

The Codex transcript is the source of truth for this report. It can contain
multiple cumulative `token_count` snapshots, model-setting changes, and older
fallback usage records. The implementation therefore attributes deltas from
the reconstructed cumulative counter instead of summing every snapshot.

## What changed

- `helper stats` now reports one detailed usage block for every observed
  model/service-tier combination, with the same input, cached-input,
  non-cached-input, cache-hit, output, reasoning-output, and total-token
  fields used by the existing conversation summary.
- Both native `token_count` snapshots and older per-turn fallback usage records
  are attributed to the model and tier active for that turn.
- Repeated snapshots, native counter resets, missing intermediate records, and
  cumulative-counter recovery continue to use the existing reconstruction
  rules. Per-model/tier totals use the resulting usage deltas, so they cannot
  double-count a repeated snapshot.
- Model and tier metadata are HTML-escaped in Teams responses. The text and
  HTML renderers keep the same section structure as the existing stats output.
- If a transcript does not record a model or service tier for a portion of the
  chat, that portion is kept in an explicit `unknown` bucket. The Analysis
  section says how much metadata is missing; the helper never guesses `default`
  or silently merges unknown usage into a named tier.
- Work-chat and Control-chat help now describe the model/tier breakdown.

## Test and CI coverage

- Added parser tests for multiple models and tiers, fallback usage, missing
  metadata, native snapshot deduplication, and deterministic output ordering.
- Added HTML escaping coverage and an end-to-end bridge test that reads a
  linked transcript and sends the breakdown through the real helper response
  path.
- The credential-free `Teams helper stats regressions` CI step runs the full
  `ParseCodexTokenStats.*`, formatting, HTML, and bridge test set. It uses only
  synthetic JSONL fixtures; no OpenAI, NVIDIA, Teams, proxy, or file-write
  credential is present or required.
- Local qualification for this candidate includes focused Teams tests,
  `go test ./...`, `go vet ./...`, and `git diff --check`. GitHub Actions must
  still pass on all configured release matrix jobs before this RC is treated as
  validated.

This is a prerelease. Existing helpers can opt in from the Teams Control chat
with `helper update prerelease`.
