## Why

Harden Windows desktop-app launch and installer behavior reported by users, and add a managed macOS ChatGPT app upgrade path without selecting or modifying the system-wide app.

## What changed

- Detect native Windows token elevation, warn when `cxp app` is elevated, and refuse managed app installation or upgrade writes when the token is elevated or cannot be verified. Existing verified managed and Store apps may still launch. WSL and other platforms do not use this policy.
- Verify the launched managed Windows app image with CIM process path and creation-time data instead of relying on `Process.MainModule.FileName`.
- Make a usable Windows installer checksum authoritative, preserve existing binaries on mismatch, and isolate and clean per-install temporary downloads.
- Support `--upgrade-codex-app` on Intel and Apple Silicon macOS. Use only a verified app under `~/Applications`, preserve its path, stage and validate the replacement, refuse downgrades and updates while ChatGPT/Codex is running, and recover the previous bundle after an interrupted swap.

## Validation

- Focused Go regression tests, Windows PowerShell checksum/concurrency and elevation/launch tests, Windows and macOS cross-compilation, CI shard-contract tests, macOS smoke-script syntax validation, and `git diff --check` passed locally.
- The full Go suite completed with environment/test failures: Windows PowerShell parse checks could not reach PowerShell through WSL (`UtilBindVsockAnyPort`), and `internal/helperruntime/TestLaunchKeepsExplicitSameBasePrereleaseActive` failed. Native Windows and macOS workflows provide additional platform coverage.
- The Windows managed-app end-to-end smoke was not completed locally because a pre-existing ChatGPT/Codex process was detected; it was left untouched. The macOS DMG install-and-upgrade network smoke is configured in CI and was not executable on this Linux/WSL host.

## Compatibility

- The Windows elevation policy does not claim to resolve AppX package-identity launch failures; the native AppX/unpackaged and standard/admin matrix remains to be verified. Windows Defender reputation/false positives remain separate from checksum integrity and are not claimed fixed.
- macOS upgrades operate at the selected `~/Applications` path. Quit every ChatGPT/Codex instance and do not reopen one through Finder until the update finishes. CXP cannot lock Finder launches, and OpenAI updater background writes and same-bundle LaunchServices forwarding remain unverified; CXP is not guaranteed to be the only updater.
