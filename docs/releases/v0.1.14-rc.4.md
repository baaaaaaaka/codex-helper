## Why this prerelease exists

`v0.1.14-rc.4` is the fully qualified successor to `v0.1.14-rc.3`. It contains the same unified official and third-party Codex model-routing implementation, plus a portability correction found by the first main-branch compatibility run.

The first candidate's Release workflow, binaries, local full suites, clean Docker suites, and real GPT-to-NVIDIA-to-GPT routing all passed. The broader main CI exposed one additional test-environment assumption: a Git-backed profile test invoked the `git` executable even inside the minimal CentOS 7, Rocky 8, and Ubuntu 20.04 runtime containers, whose purpose is to validate the static CXP binary without development tools installed. All three containers therefore failed before testing product behavior.

This candidate makes that development-tool prerequisite explicit. Environments with Git still execute the complete real repository clone/sync test; deliberately minimal runtime images skip only that Git-dependent test. CXP's production behavior when Git is missing remains a clear actionable error.

## Unified model routing included in this candidate

- Merge the signed-in Codex account's live official model catalog with verified third-party profiles, always listing official GPT models first and showing the exact default.
- Keep the native official-model path unchanged when no third-party profiles are configured.
- Preserve the exact official model slug during native fallback; never silently replace a selected GPT model with a default.
- Sync externally maintained JSON profile repositories, refresh them every 30 minutes, share one credential across multiple models, and hide third-party models until real authentication succeeds.
- Automatically reverify changed Git profiles, preserve compatible legacy local profiles, and warn whenever a last-known-good backup JSON is active.
- Expose per-model protocol, reasoning, tools, parallel tools, strict schema, streaming, context/output limits, usage/cache normalization, retry, and compatibility controls without rebuilding CXP.
- Support GPT web-search delegation only when a selected third-party model lacks native search.

## Reliable Teams model switching

- `model list`, `model status`, `model switch`, and `model fork` operate on the merged verified catalog.
- Model and effort are captured per queued turn. Existing queued/running work keeps its original provider, model, effort, and thread.
- A switch requested during active work is persisted as pending. Later turns capture the pending generation, and activation occurs at the exact queue boundary.
- Queue capture and switching share one serialization boundary, removing generation races.
- Restart recovery binds journals only when model generation and runtime identity match.
- Re-selecting the same runtime is a no-op; unsupported explicit effort resets to the destination model default with a targeted notice, while automatic/default adjustments remain silent.

## Responses compatibility

- Normalize available prompt, completion, reasoning, and cached-input usage without fabricating fields a provider omits.
- Preserve reasoning and tool history where providers require it.
- Configure provider-specific reasoning parameters, sampling suppression, tool-choice restrictions, schema stripping, call ID/name limits, parallel-tool policy, SSE assembly, termination, retry classification, and request clamping.
- Cover NVIDIA-hosted DeepSeek, GLM, MiniMax, Nemotron and existing MiMo profiles while keeping the schema extensible for future OpenAI-compatible deployments.

## Qualification and regression coverage

- Full `go test ./...`, exact CI `-parallel=16` runs with and without coverage, `go vet ./...`, actionlint, and `git diff --check`.
- Total Linux coverage of 73.7%; model-profile and Responses-adapter coverage above 75% and 80%, respectively.
- Focused race coverage for queue/switch serialization and pending-generation activation.
- JSON and SQLite restart tests for active and pending models, effort snapshots, and generation-aware thread journals.
- Windows amd64 cross-compilation and a clean Go 1.25 Docker run of the key CLI, Teams, model-profile, and adapter packages.
- Static CLI test execution in the same Git-less CentOS 7, Rocky 8, and Ubuntu 20.04 compatibility containers used by CI.
- Real regulated-account routing through the current official Codex binary: GPT-5.6 Luna to an NVIDIA-hosted model and back to GPT-5.6 Luna, including model identity, usage fields, and official prompt-cache continuity.
- Gated scheduled GitHub Actions coverage for real official-to-NVIDIA-to-official routing; repositories without opt-in secrets skip it safely.
