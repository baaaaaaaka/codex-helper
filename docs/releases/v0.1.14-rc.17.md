## Why this follow-up prerelease exists

`v0.1.14-rc.16` added model/service-tier token accounting and passed its
credential-free local qualification. The first tag-triggered CI run also
exercised a release-safety check that had not been covered by the previous
matrix: the repository already had the stable `v0.1.14` tag, but the SQLite
upgrade fixture inventory still stopped at `v0.1.13`. All three state-perf
platform jobs failed on that missing fixture, before any helper-stats test was
run.

This candidate keeps the `rc.16` tag immutable and adds the missing official
release fixture. It makes the stable-tag guard pass while preserving the
model/tier stats implementation unchanged.

## Included behavior

- `helper stats` reports detailed token usage for every observed model/service
  tier combination, including input, cached/non-cached input, cache-hit rate,
  output, reasoning output, and total tokens.
- Native cumulative `token_count` deltas, repeated snapshots, counter resets,
  recovery, and legacy per-turn fallback usage are handled without double
  counting.
- Missing model or service-tier metadata stays in an explicit `unknown`
  bucket and is called out in Analysis; it is never guessed as `default`.
- Text and HTML Teams responses are escaped and the Work/Control help text
  describes the new breakdown.
- The official-release SQLite fixture inventory now includes `v0.1.14` as a
  SQLite-v5 upgrade source. The stable-tag guard therefore catches future
  final releases immediately instead of failing later in a release matrix.

## Test and CI coverage

- Model/tier parser, reset, fallback, unknown-metadata, deterministic ordering,
  HTML escaping, and bridge response tests are covered by the credential-free
  `Teams helper stats regressions` CI pattern.
- `TestSQLiteOfficialReleaseStoresUpgradeToCurrent` and
  `TestSQLiteOfficialReleaseFixtureListCoversStableTags` now run with the
  actual stable-tag inventory and include `v0.1.14`.
- No OpenAI, NVIDIA, Teams, proxy, or file-write credential is present or
  required by any of these tests.
- Local qualification: focused stats and release-fixture tests, race-enabled
  Teams stats tests, `go test ./...`, `go vet ./...`, and `git diff --check`.
  GitHub Actions must still finish every main-CI and RC-release matrix job
  before this candidate is considered validated.

This is a prerelease. Existing helpers can opt in from the Teams Control chat
with `helper update prerelease`.
