# v0.1.22-rc.15

## Why

The `v0.1.22-rc.8` Teams safety fixes were published from a side branch and
were not present in the later `rc.9` through `rc.14` line. Those releases could
therefore still lose execution ownership around cancellation, continuation,
and transcript synchronization.

This prerelease puts the execution-anchor fixes back on the current `main`
line and provides a single commit for CI and release validation.

## What changed

- Added durable unresolved-execution anchors and explicit cancellation-fence
  reconciliation so an interrupted or unconfirmed Codex turn cannot be
  retried or completed under an unverified owner.
- Added source-proven transcript checkpoints, parent-fork fences, and
  unresolved-continuation barriers for linked Teams transcript delivery.
- Preserved current `main` durable Teams chat routing and queue-only fork
  behavior while reconciling the rc8 store, bridge, app-server, and CLI
  changes.
- Kept ChatGPT app `turn_context` bookkeeping checkpointable without exposing
  it to Teams; only an explicitly identified context record is treated as an
  execution continuation boundary.
- Added regression, SQLite/JSON compatibility, fork, history, cancellation,
  and execution-anchor coverage.

## Validation

- `CXP_RUNTIME_DISABLE=1 go test ./internal/codexrunner -count=1 -timeout=45m`
- `CXP_RUNTIME_DISABLE=1 go test ./internal/teams/store -count=1 -timeout=45m`
- `CXP_RUNTIME_DISABLE=1 go test ./internal/teams -count=1 -timeout=45m`
- `CXP_RUNTIME_DISABLE=1 go test ./internal/cli -count=1 -timeout=45m`
- `CXP_RUNTIME_DISABLE=1 go test ./... -run '^$' -count=1`
- `CXP_RUNTIME_DISABLE=1 go vet ./...`
- Focused history, transcript backfill, continuation, and durable-routing
  regressions.
- Stable-path benchmarks for bounded history scans, unchanged-tail polling,
  transcript delta reads, execution-anchor persistence, and no-op store
  updates with `-benchmem`.

The full local suite passed for all packages except the pre-existing
`internal/helperruntime/TestLaunchKeepsExplicitSameBasePrereleaseActive`
baseline failure; `internal/helperruntime` was not changed by this release.
The GitHub release workflow remains the final multi-platform gate.

## Compatibility

The prerelease preserves the existing `v0.1.22` runtime version line and adds
backward-compatible durable fields for execution ownership and transcript
provenance. JSON and SQLite stores remain supported. No public Teams message
protocol is changed. This is a prerelease for validating the repaired release
line and does not replace a stable release.
