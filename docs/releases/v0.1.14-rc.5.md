## Why this prerelease exists

`v0.1.14-rc.5` completes the cross-platform qualification of the unified official and third-party Codex model-routing work introduced in the earlier `v0.1.14` candidates. It keeps the native Codex experience unchanged for users who configure no third-party models, while allowing verified external profiles to coexist with the signed-in account's official GPT catalog in CXP, Codex CLI/App routing, and Teams Work chats.

The earlier candidates passed the local full suite, clean Linux containers, release packaging, and real regulated-account GPT-to-NVIDIA-to-GPT routing. Broader main-branch qualification then exposed assumptions that only appear on minimal Linux images, macOS temporary paths, and Windows filesystem and environment semantics. This candidate fixes those assumptions rather than weakening the product checks, and adds diagnostics that make future platform-specific CI failures actionable.

## Unified official and third-party model routing

- Merge the signed-in Codex account's live official model catalog with authenticated third-party profiles, keep official GPT models first, and identify the exact default model.
- Preserve the native official-model path when no third-party profile is configured, and preserve the selected official model slug if the unified gateway cannot start.
- Sync externally maintained JSON profile repositories, refresh them every 30 minutes, let one credential serve multiple models, and expose a third-party model only after authentication succeeds.
- Reverify changed profiles automatically, migrate compatible legacy profiles without unnecessary prompts, and warn whenever the active configuration comes from a last-known-good backup JSON.
- Expose model-specific reasoning, tool, schema, streaming, context/output, retry, usage/cache, and protocol compatibility controls so provider changes can be tuned without rebuilding CXP.
- Delegate web search to a signed-in GPT agent only for third-party models that do not provide native search.

## Reliable Teams switching and recovery

- `model list`, `model status`, `model switch`, and `model fork` use the same merged, verified catalog.
- Queue capture and model switching share one serialization boundary. Queued and running turns retain their captured provider, model, effort, generation, and thread even if the chat is switched concurrently.
- A switch requested while work is active is stored as pending and activates at the precise queue boundary; a no-op switch preserves the current thread.
- Explicit effort is retained only when the destination supports it. Unsupported values reset to that model's default with a targeted notice, while automatic/default corrections remain silent.
- Restart recovery restores a thread only when its generation and runtime identity match, preventing conversations from resuming against the wrong provider.
- Delegation-state reads tolerate the brief Windows sharing violation that can occur while another process atomically replaces the state file, but malformed or persistently unreadable state still fails closed.

## Cross-platform corrections found during qualification

- Minimal CentOS 7, Rocky Linux 8, and Ubuntu 20.04 runtime images no longer fail a development-only repository-clone test solely because Git is intentionally absent. Git-equipped CI still performs the real clone and sync path, and production CXP still reports a clear missing-Git error.
- Synced repository roots are canonicalized before containment checks. This accepts legitimate macOS `/var` to `/private/var` and Windows short-name to long-name resolution while continuing to reject files and symlinks that truly escape the repository.
- The cross-platform containment regression test compares canonical paths rather than raw temporary-directory spellings, so it verifies the security boundary without treating those legitimate macOS and Windows aliases as product failures.
- Windows loopback proxy bypass setup now merges every case-insensitive `NO_PROXY` variant without losing the user's existing hosts, then adds `127.0.0.1`, `localhost`, and `::1` once.
- Private-file tests account for Windows ACL semantics instead of requiring POSIX `0600` mode bits that Windows does not represent, while POSIX platforms continue to enforce the exact private mode.
- Windows delegation-state reads retry only transient file-sharing failures with a short bounded backoff, eliminating an atomic-replacement race without masking corruption or indefinite I/O failure.
- Cross-platform CI now preserves complete Go test output, retries the relevant package only for diagnosis, annotates the exact failing test, and identifies the failing command in distro smoke jobs.

## Responses and provider compatibility

- Normalize prompt, completion, reasoning, and cached-input usage when the provider returns them, without inventing unavailable measurements.
- Preserve reasoning and tool history for providers that require it.
- Configure per-model reasoning parameters, sampling suppression, tool-choice restrictions, schema stripping, tool-call ID/name limits, parallel-tool policy, SSE assembly and termination, retry classification, and request clamping.
- Include tuned profiles for NVIDIA-hosted DeepSeek V4/V4 Pro, GLM 5.2, MiniMax M3, Nemotron 3 Ultra, Kimi 2.6, and the existing MiMo path while keeping the schema extensible.

## Qualification evidence

- Full `go test ./...`, the exact main-CI `-timeout=20m -parallel=16` suite with and without coverage, `go vet ./...`, actionlint, and `git diff --check`.
- Total Linux coverage of 73.7%; model-profile coverage above 75% and Responses-adapter coverage above 80%.
- Race-focused coverage for queue/switch serialization, pending-generation activation, and persisted-state recovery.
- JSON and SQLite restart tests for active and pending profiles, effort snapshots, model generations, and generation-aware thread journals.
- Real Git repository clone/sync tests, canonical-root and escaping-symlink tests, and Git-less static-binary tests inside the same CentOS 7, Rocky Linux 8, and Ubuntu 20.04 images used by CI.
- Windows amd64 binaries exercised through actual Windows process interop for profile launch, Git sync, auth copy, proxy preservation, web-search fallback, and repeated delegation cancellation/state replacement.
- Real regulated-account routing through the current official Codex binary: GPT-5.6 Luna to an NVIDIA-hosted third-party model and back to GPT-5.6 Luna, including exact model identity, available usage data, and official prompt-cache continuity.
- Gated scheduled GitHub Actions coverage for the real official-to-NVIDIA-to-official route. Repositories without the required opt-in variable and secrets skip that external test safely.
