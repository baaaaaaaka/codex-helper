# v0.1.22-rc.83

## Why

Large history lists, preview reads, text wrapping/search and refresh could block the TUI event loop. This prerelease keeps selection, navigation and quit responsive while that work completes.

## What changed

- Reuse project/session list snapshots between keyboard handling and drawing, with explicit invalidation for refresh, filters and subagent expansion.
- Move preview reads, layout/search and refresh to bounded workers. Each worker retains at most one running job, one replacement and one result; generations reject stale results, including A/B/A selection changes.
- Preserve complete preview text, selection identity and saved scroll. Pending layouts show `Preparing preview...`; slow refresh and full wake queues cannot prevent cancellation or quit.
- Bound recent raw previews to six entries and 24 MiB, with one oversized selected preview allowed alone. Keep the existing wrapped-preview budget.
- Add 14 regression tests, Linux TUI race coverage, and native Linux/macOS/Windows release preflight coverage.

## Validation

- Complete `go test -p 1 -parallel=4 -timeout=12m ./...` passed on Go 1.25.11 through the development skill’s ephemeral Docker harness, including all black-box E2E scenarios. Container concurrency was limited to fit its existing PID budget.
- TUI race tests passed for 20 iterations on Go 1.25.11; all 14 new tests also passed through the release preflight selection.
- Windows amd64 and macOS arm64 TUI tests cross-compile locally. Native execution and repository-wide gates run in CI and the release workflow.
- A 160x50 simulation replay at 20 keys/second, using 879 top-level/orphan sessions and 7,086 subagents, measured ordinary-key P95 of 1.39 ms (previously 11.63 ms). Switching an 8.61 MB preview measured P95 of 2.09 ms (previously 391.79 ms), with all 120 injected keys handled and no queue rejections. Full preview display settled about 70 ms after switching stopped.
- Measurements used WSL2 and Go 1.26.3; they measure enqueue-to-next-screen-show, excluding terminal transport. Private conversation fixtures are excluded from the source and release.

## Compatibility

No persisted cache schema, history format, refresh frequency or flush-policy change. Full text, Unicode wrapping and search remain available. Preview scrolling waits for layout completion. An already running filesystem/SQLite preview read cannot be interrupted; its cancelled result is ignored. Cache retention budgets are not a total process-memory limit. This is a prerelease, without final-version promotion.
