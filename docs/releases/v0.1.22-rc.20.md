# v0.1.22-rc.20

## Why

Ship the latest `main` changes after `v0.1.22-rc.19` with the remote TUI transport contract
unchanged and the legacy-history remediation documented and validated.

## What changed

- Keep the Unix PTY supervisor stdin open for the lifetime of the supervised process.
- Refresh the Codex compatibility table used by CXP's managed Codex checks.
- Add the executed legacy-history paging and safe-migration checklist.

## Validation

- `go test ./... -count=1`
- Focused remote broker, app-server transport, Codex launch, and Teams resume tests.
- The related official Codex app-server/TUI changes were validated separately in the clean Codex
  worktree and are documented in the checklist.

## Compatibility

- CXP's app-server stdout scanner remains a finite defensive limit and the remote broker remains
  byte-transparent.
- Teams metadata-only resume and its checkpoint/outbox state machine are unchanged.
- The legacy-history paging implementation is an official Codex app-server/TUI change; this CXP
  release does not bundle a Codex binary. Users need the corresponding Codex build installed for
  that fix to affect `cxp resume` in TUI.
