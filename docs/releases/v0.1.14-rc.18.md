# v0.1.14-rc.18

## Why this follow-up release exists

The `v0.1.14-rc.17` release workflow exposed a release-matrix edge case that
was unrelated to the Teams token-statistics feature. Because the repository
already has a published `v0.1.14` final release, the Windows compatibility
matrix tried to exercise an upgrade from `v0.1.14` to `v0.1.14-rc.17`. A final
release is semantically newer than its own prerelease, so that scenario is a
downgrade rather than a supported upgrade. The old binary consequently left
no pending replacement and the smoke test failed.

## What changed

- Release-matrix selection now omits the stable `vX.Y.Z` fixture when the
  target is `vX.Y.Z-rc.N`.
- All other historical stable releases and the explicitly retained rescue RC
  fixtures remain covered.
- Added unit tests proving both prerelease exclusion and unchanged stable
  target behavior.

This only changes which compatibility scenarios are valid for a prerelease;
it does not weaken upgrade coverage or change runtime/update behavior.

## Validation

- `python3 -m unittest scripts/tests/test_helper_release_matrix.py`
- Live release inventory selection for `v0.1.14-rc.18` produced the expected
  matrix without `v0.1.14`.
- No credentials or provider tokens are present in this change or required by
  its tests.
